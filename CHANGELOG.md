# Changelog

## 3.1 - Toolkit modularization and safety improvements

- Expanded the launcher with a clear menu and graceful missing-module reporting.
- Added shared path, reporting, finding, confirmation, and logging helpers.
- Added system and hardware inventory, network and storage interactive diagnostics, and read-only security/admin inventories.
- Added explicitly confirmed SFC/DISM and DNS cache operations; no automatic repairs.
- Added report/log browsing and privacy/safety documentation.
- Runtime verification on Windows 10/11 remains outstanding.
